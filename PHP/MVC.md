## MVC basics  

**Model**: логика приложения, здесь описывается обработка данных.  
**View**: представление обработанных данных пользователю. Отправили запрос -> Controller (маршрутизировали запрос) -> Обработали запрос (произвели обработку данных) -> Отобразили итоговый результат (View). Содержит HTML разметку и вставки PHP кода.  
**Controller**: управляет запросами от пользователя. Связующее звено между компонентами приложения. Не должен содержать обработку данных запроса (например SQL обращения), не должен содержать HTML и какой-либо другой код использующийся в View.  

## Структура MVC приложений  

**ДИРЕКТОРИЯ ПРИЛОЖЕНИЯ**
  - **app**
    - Controllers
    - Models
    - Views
  - **public**  // Здесь создается index.php.
  - **core**    // Здесь создаются основные классы приложения; Например, Application, Router, Request, Response, и другие.
  - **config**  // Здесь хранятся файлы конфигураций, маршрутов;
  - **vendor**  // Директория создается composer'ом.
  - **helpers**
  - composer.json  // С помощью этого файла подклчаем autoload и 3-rd party зависимости.
