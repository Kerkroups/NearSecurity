## Взаимодействие PHP с HTML  

При передаче значений методом GET, параметры запроса автоматически перемещаются PHP в суперглобальный массив $_GET. Имена параметров выступают в качестве ключей массива. В качестве GET-параметров могут выступать элементы массива, в этом случае суперглобальный массив становиться двумерным (```http://localhost/array.php?id[]=1&id[]=2```).  

В двуменрном массиве $_GET элементам могут быть автоматические назначены числовые индексы начиная с 0, однако индексы и ключи могут назначаться элементам непосредственно в строке запроса (```http://localhost/array.php?id[a]=1&id[b]=2```). GET-параметры и их значения могут содержать недопустимые с точки зрения URL символы, которые при формировании URL обязательно должны преобразоваться в безопасный формат. Для такого преобразования в PHP предусмотренны специальные функции, например urlencode() (```srting urlencode(string $str)```).  

Для разбора строки запроса предназначена специальная функция parse_url() (```mixed parse_url(string $url [, int $component = -1])```). Функция принимает в качестве первого параметра строку запроса и возвращает отдельные его компоненты в виде ассоциативного массива со следующими ключами: scheme, host, port, user, pass, path, query, fragment. Если функция parse_url() принимает второй параметр $component, вместо массива возвращается строка с одним из компонентов строки запроса.  

При передаче значений в теле запроса методом POST, параметры запроса автоматически перемещаются PHP в суперглобальный массив $_POST.  

Для файлов, загружаемых на сервер, предназначен отдельный массив $_FILES, двумерный массив который хранит характеристики загружаемого файла (name, size, type, tmp_name). Проверить успешность загрузки файла на сервер можно при помощи специальной функции is_uploaded_file(), которая принимает в качестве единественного параметра name (```$_FILES['filename'['name']]```) и возвращает true в случае успешной загрузки и false в случае неудачи. Переместить файл можно при помощи функции move_uploaded_file(), которая имеет следующий синтаксис: ```bool move_uploaded_file(string $filename, string $destination)```, в качестве первого параметра $filename функция принимает путь к загруженному файлу, а в качестве второго параметра $destination - путь, куда файл должен быть перемещен.  

## Суперглобальные массивы  
Список суперглобальных массивов: ```$_GET, $_POST, $_FILES, $_COOKIE, $_SESSION, $_REQUEST, $_ENV, $_SERVER, $GLOBALS```.  

**$_COOKIE**: массив который хранит значения установленные методом setcookie().  

```bool setcookie(string $name [, string $value = "" [, int $expire = 0 [, string $path = "" [string $domain = "" [, bool $secure = false [, bool $httponly = false ]]]]]])```.  
$name - имя cookie;  
$value - значение, хранящееся в $name;  
$expire - время в секундах. По истечению этого времени cookie удаляется с машины клиента;  
$path - путь, по которому доступен cookie;  
$domain - домен, из которого доступен cookie;  
$secure - если True, cookie передается по защищенному протоколу HTTPS;  
$httponly - если True, создается cookie недоступный через JavaScript;  

Cookie записывается на жестком диске клиента только в том случае, если выставляется время жизни cookie; в противном случае размещается в оперативной памяти и действует до конца сеанса, т.е. до того момента, пока пользователь не закроет окно браузера.  

**$_SESSION**: хранит данные сессии в формате "ключ/значение" на стороне сервера. Для каждого из посетителей сохраняется собственный набор данных. Для идентификации каждому новому клиенту назначается уникальный номер-идентификатор сесии (SID), который передается через cookie. Время жизни сесии задается в конфигурационном файле php.ini.  

Оба механизма, сесии и cookie взаимно дополняют друг друга. Cookie обычно применяются для долгосрочных задач и хранения информации, которая относится исключительно к конкретному посетителю (личные настройки, логины, пароли, и т.п.). Сесии хранятся на сервере, и продолжительность их существования определяется администратором сервера. Они рпедназначены для краткосрочных задач.  

Директива ```session.save_path``` в файле php.ini позволяет задать путь к каталогу, в котором сохраняются файлы сессий. Функция ```session_start()``` должна вызыватьсядо начала вывода информации в окно браузера. После инициализации сесии появляется возможность сохранять информацию в суперглобальном массиве $_SESSION.  

```session_start();``` - инициализирует сессию, в вкладке браузера cookie появляется PHPSESSID. Такж был создан файл с данными сессии.  

Массив $_SESSION перед сохранением в файл подвергается сериализации (функция session_encode()). Сериализованые данные разделяются символом '|'. Удалить значение с сесии можно с помощью конструкции ```unset($_SESSION[key])```. Завершить сессию можно с помощью функции ```session_destroy()```, но файл сессии будет продолжать существовать.

**$_SERVER**: содержит параметри извлеченные из HTTP ответа.

## Массивы  
Массив - индексированая совокупность переменных одного типа. Каждая переменная или элемент массива имеет свой индекс, т.е. все элементы массива последовательно пронумерованны от 0 до N - 1, где N - размер массива.  

Создание массива: ```$arr = array('First', 'Second',  'Third');```  
Альтернативный способ создания массива: ```$arr = ['First', 'Second',  'Third'];```  
Еще один способ создания массива: присвоение неинициализированным элементам массива новых значений: ```$arr[10] = 'First';```  
Автоматическое назначение индекса: ```$arr[] = 'First';```  
Еще один способ создания массива: приведение скалярной переменной (integer, float, string, boolean) к типу array - результатом этого становиться массив, содержащий один элемент и индексом 0 и значением, равным значению переменной.  
```
$var = 'First, Second';
$arr = (array) $var;
print_r($arr);

Array
{
  [0] => First, Second
}
```  

Назначение индекса первому элементы массива: ```$arr = [10 => 'First', 'Second', 'Third'];``` // Индексация элементов массива бует начинаться с индекса 10. В приведенном примере, элементов с индексами 0,1 .. 9,13 не существует, обращение к ним воспринимается как обращение к неинициализированной переменной, т.е. переменной имеющеей значение null. Назначать индексы можно в любом порядке. Все непронумерованные элементы будут автоматически получать значение, равное максимальному и увеличенному на единицу.

**Ассоциативные и индексные массивы**  
В качестве индексов массивовв могут віступать не только числа но и строки. Один массив может иметь как числовые индексы так и строковые ключи. Ключи ассоциативного массива являются обычными строками, поэтому для обращения к элементам можно использовать как двойные так и одинарные кавычки.  

Создание ассоциативного массива (key/value): ```$arr = ['one' = '1', 'two' => '2'];```  
Создание элементов ассоциативного массива посредством прямого обращения к ним: ```$arr['one'] = '1';```. Если осуществляется попытка создания двух элементов массива с одинаковыми ключами, создается один элемент с последним значением. Ключи ассоциативных массивов, как и обычные строки, зависят от регистра.  

**Многомерные массивы**  

```
$arr = [
  'One' => ['First', 'Second', 'Third'],
  'Two' => ['Fourth', 'Fifth', 'Six'],
  'Three' => ['Seven', 'Eight', 'Nine']
];

$arr['One'][0]; // 'First'.
$arr['Two'][1]; // 'Fifth'.
$arr['Three'][2]; // 'Nine'.
```

**list()**  
Преобразует элементы массива в обычные переменные.  
```
$arr = [1,2,3];
list($one, $two, $three) = $arr;
```
Конструкция list() работает только с числовыми массивами, нумерация индексов котрых начинается с нуля. Количество элементов в разбираемом массиве и в круглых скобках конструкции list() может не совпадать. Если элементов больше чем нужно, лишнее просто будет отброшены, если меньше - часть переменных останется неинициализированной. Часть первых элементов массива может быть пропцщенна, для этого достаточно указать соответствующее количество запятых.  

list() может применяться для обмена значений переменных без переменной-посредника: ```list($x, $y) = [$y, $x]```.  

**Цикл foraech**  
Обход массива в цикле можно организовать при помощи цикла foraech, который специально создан для ассоциативных массивов и имеет следующий синтаксис:  
```
foreach($array as [$key =>] $value) {
  операторы;
}
```
В качестве первого аргумента конструкции foreach обязательно должен выступать массив.  
```
$arr = [
  'first' => '1',
  'second' => '2',
  'third' => '3'
];

foreach($arr as $index => $val) {
  echo "$index = $val <br />";
}
```

Вариант обхода массива в цикле foreach без $key:  
```
$arr = [
  'first' => '1',
  'second' => '2',
  'third' => '3'
];

foreach($arr as $val) {
  echo $val; // 123
}
```

Обход много мерных массивов проводиться с помощью вложенных циклов foreach, пр этом число вложенных циклов соответствует размерности массива:  
```
$arr = [
  'One' => ['First', 'Second', 'Third'],
  'Two' => ['Fourth', 'Fifth', 'Six'],
  'Three' => ['Seven', 'Eight', 'Nine']
];

// Выводим ключи
foreach($arr as $index => $val) {
  echo "<b>$index</b><br />";

// Выводим значения для каждого ключа
  foreach($val as $number) {
  echo <li>$number</li>;
  }
}
```

**Слияние массивов**  
Сличние массивов может осуществляться с помощью оператора + (наряду с + допускается использование +=). Если в массивах присутвтуют элементы с одинаковыми индексами, в результирующий массив попадают элементы из лувого массива. Для того, чтобы в результирующий массив попали элементы обоих массивов, вместо оператора + используют специальную функцию [array_merge()](https://www.php.net/manual/en/function.array-merge.php), которая имеет следующий синтаксис: ```array array_merge()array $array1 [, array $...]```. Функция array_merge() может принимать в качестве параметров более двух массивов.  

**Сравнение массивов**  
Как и любые две переменные, массивы можно сравнивать при помощи операторов равентва == и неравенства !=. Два массива считаются равными, если количество и значения ключей и значений совпадают.  
Операторы эквивалентности === и неэквивалентности !== соответтственно схожи с операторами равентсва и неравенства. Два массива считаются эквивалентными, если совпадают не только количество их элементов, ключей и значений, но имеется и совпадение типов значений. Интересно отметить, что массивы, в которых используются ключи разного типа, не считаются неэквивалентными.  

**Проверка существования элементов в массиве**  
Проверить, существует тот или иной элемент массива, можно при  помощи контрукции [isset()](https://www.php.net/manual/en/function.isset.php). Существование массива также можно проверить с помощью конструкции isset(). Если необходимо убедиться, является ли текущая переменная массивом, используют функцию [is_array()](https://www.php.net/manual/en/function.is-array.php).  

Функция [in_array()](https://www.php.net/manual/en/function.in-array.php) осуществляет поиск значения в массиве и имеет следующий синтаксис: 
```
bool in_array(mixed $value, array $arr [, bool $strict = false])
```
Функция ищет в массиве $arr значение $value и возвращает true, если значение найдено, и false - в проитвном случае.  

Для поиска заданного ключа в массиве можно воспользоваться функцией [array_key_exist()](https://www.php.net/manual/en/function.array-key-exists.php), которая имеет следующий синтаксис:  
```
bool array_key_exist(mixed $key, array $array)
```
Функция возвращает true, если ключ $key найден в массиве $array.  

Найти ключ массива по значению позволяет функция [array_search()](https://www.php.net/manual/en/function.array-search.php), которая имеет следующий синтаксис:  
```
mixed array_search(mixed $value, array $arr [, bool $strict = false])
```
Функция ищет значение $valueв массиве $arr и, если значение найдено, возвращает соответствующий ключ, в противном случае возвращается false.  

**Удаление элементов массива**  
Удаление элемента массива, как и любой другой переменной, осуществляется при помощи конструкции [unset()](https://www.php.net/manual/en/function.unset.php).  

## Функции  

**Динамчическое имя функции**  
По аналогии с переменными, имя функции может быть динамическиим и храниться в строковой переменной - передача такой переменной оператором круглых скобок (ч параметрами, если они требуются) приводит к вызову функции.  
```
function hello() {
  return 'hello';
}
function bye() {
  return 'bye';
}
$var = rand(0,1) ? 'hello':'bye';
$var();
```

**Анонимные функции**  
Анонимные функии - это функции без имени. Анонимные функции допускается передавать в качестве аргументов другим функция.  
```
$var = function (...$str) { операторы; }
$var(параметры);
```

**Замыкания**  
Замыкание - это функция, которая запоминает состояние окружения в момент своего создания. Даже если состояние затем изменяется, замыкание содержит првоначальное состояние. Замыкание в PHP применимо только к анонимным функция. Для активизазции необходимо использовать ключевое слово use, а за ним в скобках можно указать переменные, которые должны войти в замыкание.  
```
$message = "Work cannot bu continue due to error's";
$check = function(array $errors) use ($message) {
  if (isset($errors) && count($errors) > 0 ) {
    echo $message;
    foreach($errors as $error) { echo "$error <br />"; }
  }
}
$check([]);
// ...
$errors[] = 'Enter username';
$check($errors);
// ...
$message = "Requirements list"; // Уже не изменить.
$errors = ['PHP', 'JS', 'Redis'];
$check($errors);
```
Основное назначение замыканий - замена глобальных переменных. В отличие от глобальных переменных, вы можете передавать внутрь функции значение, но уже не сможете изменить переменную, переданную через механизм замыкания. Самое главное - никакие изменения глобальной переменной в других частях программы не смогут повлиять на значение, переданное через замыкание.

**Динамические методы**:

В качестве первого параметра метод __call() принимает имя вызываемого метода, а в качестве второго - массив, элементами которого являются параметры, переданные при вызове. При помощи метода __call() можно эмулировать методы с переменным количеством параметров.

**Интерполяция объекта**:  
__toString() - специальный метод который пощволяет интерполировать (подставлять) объект в строку. Для подстановки значений переменных необходимо заключить строку в двойные кавычки:  
```
$number = 12345;
echo "number = $number<br />"; // number = 12345
echo 'number = $number<br />'; // number = $number
```

Такого же поведения можно добиться и от объекта, если реализовать в его классе метод __toString(), который преобразует объект в строку.  

```
class Point {

private $point;

...

public function __toString() {
  return "{{$this->x}, {$this->y}}";
}

$point = newPoint(5, 12);
echo "point = {$point}"; point = (5, 12)
}
```

## Наследование  
Наследование позволяет создать новый класс на основе уже существующего, автоматически включив в новый класс переменные и методы старого. При объявлении производного класса необходимо указать имя базового класса с помощью ключевого слова extends.  

**Перегрузка методов**  
В производном классе можно создать метод с таким же названием, что и в базовом классе, который заменит метод базового класса при вызове. В рамках производного класса остается возможность вызвать метод базового класса, обратившись к нему при помощи префикса parent::.

**Позднее статическое связывание**  
```
class Base {

  public static function title() {
    return __CLASS__;
  }
  public static function test() {
    return static::title();
  }
}

class Derived extends Base {
  public static function title() {
    return __CLASS__;
  }
}

echo Derived::test();  // Derived, если self::title() => Base.
```  

**Полиморфизм**:  
Все объекты производных классов автоматически снабжаются методами базового класса. Производные классы могут использовать методы базового класса без изменений, адаптировать их или заменять собственной реализацией. Если несколько классаов наследуются от одного базового класса, то все они будет одиноковые названия методов предоставленные базовым классом, но могут иметь разную реализацию в производном классе.

**Абстрактные классы**  
Абстрактный класс - это класс который является шаблоном для создания других классов. Абстрактным классом следует объявлять классы, которые не существуют в реальности и объекты которых заведомо не потребуются.  

**Абстрактные методы**  
Абстрактные методы это методы-заглушки в абстрактном классе. Для абстрактных методов задают их описание и список параметров без реализации. Каждый класс, который наследуется от базового класса, содержащего абстрактные методы, лбязан их реализовать. При помощи абстрактных методов исключается возможность неумышленного нарушения полиморфизма для производных классов.  

```
abstract class Base {
  abstract public function total();
  abstract public function pnumber();
  abstract public function pageLinker();
  abstract public function parameters();
}
```

**Final-методы класса**  
Если асбтрактные методы и интерфейся предназначены для того, чтобы обеспечить обязательную перегрузку методов в производных классах, то ключевое слово final решает обратную задачу. Методы, объявленные в базовом классе с ключевым словом final, не могут быть перегружены в производном классе.  

```
class Base {
  final public function finalMethod() {
    return 'Base::finalMethod()';
  }
}

class Derived extends Base {
   final public function finalMethod() { // Попытка перегрузить метод finalMethod в производном классе заканчивается ошибкой.
    return 'Base::finalMethod()';
  }
}
```
Поимимо обычных методов в качестве final-методов можно объявлять и специальные методы. Например, в качестве final-методов могут объявляться конструкторы и деструкторы.  

**Final классы**  
Класс, объявленный при помощи ключевого слова final, не может иметь наследников.  

**Анонимные классы**  
```
class Dumper {
  public static function print($obj) {
    print_r($obj);
  }
}

Dumper::print(new class {
  public $title;
  public function __construct() {
    $this->title = 'Hello, World!';
  }
});
```
Благодаря анонимным классам появляется возможность создавать объекты "на лету". Результатом выполнения скрипта будет следующая строка:  
```
class@anonymous Object ( [title] => Hello, World! )
```
При определении анонимного класса внутри другого класса, для получения доступа к защищенным членам, допускается наследовани анонимных классов.

## Трейты  
Трейты похожи на интерфейсы тем, что в одном классе может использоваться несколько разных трейтов. В отличие от интерфейсов, трейты содержат готовые методы. Их использование позволяет исключить повторные участки кода в тех случаях, когда реализация той или иной функуиональности не отличается от класса к кслассу. Для включения трейта в класс используется ключевое слово ```use```, после которого указывается имя трейта.  

**Трейты и наследоавние**  
Трейты встраиваются в цепочку наслежования таким образом, что переопределяют методы базового класса, однако методы класса, куда трейт включен, перезаписывает методы трейта.  

**Разрешение конфликтов**  
Если в двух трейтах определен метод с одним и тем же именем, возникает конфликт. Его можно разрешить, явно указав, какой из методов следует использовать, в фигурных скобках после оператора ```use```. Внутри фигурных скобок можно добавить ключевое слово ```insteadof``` для указания, какой из методов следует использовать. Кроме того, допускается применение ключевого слова ```as``` для указания нового псевдонима для конфликтующего метода.
