## Взаимодействие PHP с HTML  

При передаче значений методом GET, параметры запроса автоматически перемещаются PHP в суперглобальный массив $_GET. Имена параметров выступают в качестве ключей массива. В качестве GET-параметров могут выступать элементы массива, в этом случае суперглобальный массив становиться двумерным (```http://localhost/array.php?id[]=1&id[]=2```).  

В двуменрном массиве $_GET элементам могут быть автоматические назначены числовые индексы начиная с 0, однако индексы и ключи могут назначаться элементам непосредственно в строке запроса (```http://localhost/array.php?id[a]=1&id[b]=2```). GET-параметры и их значения могут содержать недопустимые с точки зрения URL символы, которые при формировании URL обязательно должны преобразоваться в безопасный формат. Для такого преобразования в PHP предусмотренны специальные функции, например urlencode() (```srting urlencode(string $str)```).  

Для разбора строки запроса предназначена специальная функция parse_url() (```mixed parse_url(string $url [, int $component = -1])```). Функция принимает в качестве первого параметра строку запроса и возвращает отдельные его компоненты в виде ассоциативного массива со следующими ключами: scheme, host, port, user, pass, path, query, fragment. Если функция parse_url() принимает второй параметр $component, вместо массива возвращается строка с одним из компонентов строки запроса.  

При передаче значений в теле запроса методом POST, параметры запроса автоматически перемещаются PHP в суперглобальный массив $_POST.  

Для файлов, загружаемых на сервер, предназначен отдельный массив $_FILES, двумерный массив который хранит характеристики загружаемого файла (name, size, type, tmp_name). Проверить успешность загрузки файла на сервер можно при помощи специальной функции is_uploaded_file(), которая принимает в качестве единественного параметра name (```$_FILES['filename'['name']]```) и возвращает true в случае успешной загрузки и false в случае неудачи. Переместить файл можно при помощи функции move_uploaded_file(), которая имеет следующий синтаксис: ```bool move_uploaded_file(string $filename, string $destination)```, в качестве первого параметра $filename функция принимает путь к загруженному файлу, а в качестве второго параметра $destination - путь, куда файл должен быть перемещен.  

## Суперглобальные массивы  
Список суперглобальных массивов: ```$_GET, $_POST, $_FILES, $_COOKIE, $_SESSION, $_REQUEST, $_ENV, $_SERVER, $GLOBALS```.  

**$_COOKIE**: массив который хранит значения установленные методом setcookie().  

```bool setcookie(string $name [, string $value = "" [, int $expire = 0 [, string $path = "" [string $domain = "" [, bool $secure = false [, bool $httponly = false ]]]]]])```.  
$name - имя cookie;  
$value - значение, хранящееся в $name;  
$expire - время в секундах. По истечению этого времени cookie удаляется с машины клиента;  
$path - путь, по которому доступен cookie;  
$domain - домен, из которого доступен cookie;  
$secure - если True, cookie передается по защищенному протоколу HTTPS;  
$httponly - если True, создается cookie недоступный через JavaScript;  

Cookie записывается на жестком диске клиента только в том случае, если выставляется время жизни cookie; в противном случае размещается в оперативной памяти и действует до конца сеанса, т.е. до того момента, пока пользователь не закроет окно браузера.  

**$_SESSION**: хранит данные сессии в формате "ключ/значение" на стороне сервера. Для каждого из посетителей сохраняется собственный набор данных. Для идентификации каждому новому клиенту назначается уникальный номер-идентификатор сесии (SID), который передается через cookie. Время жизни сесии задается в конфигурационном файле php.ini.  

Оба механизма, сесии и cookie взаимно дополняют друг друга. Cookie обычно применяются для долгосрочных задач и хранения информации, которая относится исключительно к конкретному посетителю (личные настройки, логины, пароли, и т.п.). Сесии хранятся на сервере, и продолжительность их существования определяется администратором сервера. Они рпедназначены для краткосрочных задач.  

Директива ```session.save_path``` в файле php.ini позволяет задать путь к каталогу, в котором сохраняются файлы сессий. Функция ```session_start()``` должна вызыватьсядо начала вывода информации в окно браузера. После инициализации сесии появляется возможность сохранять информацию в суперглобальном массиве $_SESSION.  

```session_start();``` - инициализирует сессию, в вкладке браузера cookie появляется PHPSESSID. Такж был создан файл с данными сессии.  

Массив $_SESSION перед сохранением в файл подвергается сериализации (функция session_encode()). Сериализованые данные разделяются символом '|'. Удалить значение с сесии можно с помощью конструкции ```unset($_SESSION[key])```. Завершить сессию можно с помощью функции ```session_destroy()```, но файл сессии будет продолжать существовать.

**$_SERVER**: содержит параметри извлеченные из HTTP ответа.

## Массивы  
Массив - индексированая совокупность переменных одного типа. Каждая переменная или элемент массива имеет свой индекс, т.е. все элементы массива последовательно пронумерованны от 0 до N - 1, где N - размер массива.  

Создание массива: ```$arr = array('First', 'Second',  'Third');```  
Альтернативный способ создания массива: ```$arr = ['First', 'Second',  'Third'];```  
Еще один способ создания массива: присвоение неинициализированным элементам массива новых значений: ```$arr[10] = 'First';```  
Автоматическое назначение индекса: ```$arr[] = 'First';```  
Еще один способ создания массива: приведение скалярной переменной (integer, float, string, boolean) к типу array - результатом этого становиться массив, содержащий один элемент и индексом 0 и значением, равным значению переменной.  
```
$var = 'First, Second';
$arr = (array) $var;
print_r($arr);

Array
{
  [0] => First, Second
}
```  

Назначение индекса первому элементы массива: ```$arr = [10 => 'First', 'Second', 'Third'];``` // Индексация элементов массива бует начинаться с индекса 10. В приведенном примере, элементов с индексами 0,1 .. 9,13 не существует, обращение к ним воспринимается как обращение к неинициализированной переменной, т.е. переменной имеющеей значение null. Назначать индексы можно в любом порядке. Все непронумерованные элементы будут автоматически получать значение, равное максимальному и увеличенному на единицу.

**Ассоциативные и индексные массивы**  
В качестве индексов массивовв могут віступать не только числа но и строки. Один массив может иметь как числовые индексы так и строковые ключи. Ключи ассоциативного массива являются обычными строками, поэтому для обращения к элементам можно использовать как двойные так и одинарные кавычки.  

Создание ассоциативного массива (key/value): ```$arr = ['one' = '1', 'two' => '2'];```  
Создание элементов ассоциативного массива посредством прямого обращения к ним: ```$arr['one'] = '1';```. Если осуществляется попытка создания двух элементов массива с одинаковыми ключами, создается один элемент с последним значением. Ключи ассоциативных массивов, как и обычные строки, зависят от регистра.

## Фильтрация и проверка данных  
Для того чтобы гарантировать, что ```$_GET['id']``` содеоржит число, а не строку, мы можем явно преобразоовать её к целому числу: ```$_GET['id'] = intval($_GET['id']);```.  
Проверить, является ли переданное значение числом: ```if(!is_int($_GET['id'])) exit('Value must be a number');```

## Сериализация / Десериализация:  
```
// Only allow specific classes to instantiate
unserialize($serializedData, ["allowed_classes" => ["User", "Settings"]]);

// Block ALL object instantiations (allows only primitive types like arrays, strings, integers)
unserialize($serializedData, ["allowed_classes" => false]);
```  
Passing true to allow all classes is deprecated starting in PHP 8.4 and will trigger a fatal error/type error.

**Динамические методы**:  
__call() - специальный метод предназначен для создания динамических методов:  
- если в классе не перегружен метод __call(), обращение к несуществующему методу не приведет к ошибке, а передаст управление методу __call().  

В качестве первого параметра метод __call() принимает имя вызываемого метода, а в качестве второго - массив, элементами которого являются параметры, переданные при вызове. При помощи метода __call() можно эмулировать методы с переменным количеством параметров.  

__callStatic() - статический метод позволяющий динамически создавать статические методы.  

**Интерполяция объекта**:  
__toString() - специальный метод который пощволяет интерполировать (подставлять) объект в строку. Для подстановки значений переменных необходимо заключить строку в двойные кавычки:  
```
$number = 12345;
echo "number = $number<br />"; // number = 12345
echo 'number = $number<br />'; // number = $number
```

Такого же поведения можно добиться и от объекта, если реализовать в его классе метод __toString(), который преобразует объект в строку.  

```
class Point {

private $point;

...

public function __toString() {
  return "{{$this->x}, {$this->y}}";
}

$point = newPoint(5, 12);
echo "point = {$point}"; point = (5, 12)
}
```
