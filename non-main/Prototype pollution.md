**Базовые условия для эксплуатации PP**:  
1. Допускается глубоко вложенный ввод.
2. Приложение использует лбъединения (merging): ```Object.assign(config, userInput);```; Lodash library пример ```_merge({}, userInput);```;
3. Приложение не санитизирует "ключи" ("key/value");

**Опасные "keys"**:  
- __proto__ - модифицирует текущий прототип;
- constructor.prototype - модифициоует базовый прототип через конструктор;
- prototype в функции конструктора или литерала объекта;
