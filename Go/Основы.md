## Типы данных  
Примитивные типы данных состоят из базовых составляющих элементов (строк, чисел и логических значений).  
Сложные типы являются определяемыми пользователем структурами, включающими в себя комбинацию одного или нескольких примитивных или сложных типов.  

Примитивные типы: bool, string, int, int8, int16, int32, int64, uint, uint8, uint16, uint32, uint64, uintptr, byte, rune, float32, float64, complex64, complex128.  

При определении переменной нужно задать её тип, если этого не сделать, система автоматически назначит тип автоматически.  

```
var x = "Test" // Go неявно назначит x как string;
z := int(42) // Явно обернули 42 в вызов int, обусловив его тип.  
```

## Срезы и карты (Slices, Maps)  
Срезы подобны массивам, размер которых вы можете изменять динамически, что позволяет более эффективно передавать их функциям.  
Карты это ассоциативные массивы, неупорядоченные списки пар "ключ/значение", позволяющие эффективно и быстро находить значения для уникального ключа.  

```
var s = make([]string, 0)
var m = make(map[string]string)
s = append(s, "test")
m["key"] = "value"
```

## Указатели, структуры, интерфейсы  
Указатель указывает на конкретную область памяти, позволяя извлекать хранящиеся там значения. Как и в Си, в данном случае & служит для извлечения адресса переменной, а оператор * для разыменования этого адреса, т.е. получить по нему значение.  
```
var count = int(42)
ptr := &count      // Создаем указатель, возвращая адресс переменной count.
ftm.Println(*ptr)  // Разыменовываем значение указателя и выводим значение count в stdout.
*ptr = 100         // Присваиваем новое значение переменной count с помощью оператора области памяти.
fmt.Println(count)
```

Тип struct (структура) используется для создания новых типов даннх путем определения связанных полей и методов этого типа.  
```
type Person struct {
  Name string
  Age int
}

// В типе Person присвоенном переменной р, определяем метод sayHello(). р эквивалентно self или this в других языках.
func (p *Person) sayHello() {
  fmt.Println("Hello, ", p.Name)
}
// main() точка входа в программу.
func main() {
  var guy = new (Person)
  guy.Name = "Dave"
  guy.sayHello()
}
```

В структурах отсутствуют модификаторы доступа (private, public, protected). Вместо этого область доступности определяется величиной регистра: тип и поля, начинающиеся с прописной буквы, экспортируются и являются доступными вне пакета, начинающиеся со строчной - закрытые и доступны только внутри пакета.  

Тип интерфейс (interface) можно понимать как схему или контракт.
