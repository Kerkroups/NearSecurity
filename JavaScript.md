## ОБЪЕКТЫ И МАССИВЫ  
Самым важным типом данных является "Object". Object это коллекция пар имя/значение или отображений строки на значение.  
```
let book = {
  topic: "JavaScript",
  edition: 7
};
```
**Доступ к свойствам объекта осуществляется с помощью "." или "[]".**
```
book.topic //"JavaScript"
book["edition"] // 7
```
**Новые совйства создаются посредством присваивания**
```
book.author = "Flanagan";
book.content = {} //Пустой объект не имеющий свойств.
```
**Условный доступ к свойствам с помощью "?."**
```
book.contents?.ch01?.sect1 //Не определенно, book.contents не имеет свойства ch01.
```

**Создание массива**
```
let primes = [2,3,5,7];
```
**Доступ к элементам массива осуществляется по индексам**
```
primes[0] //Первый элемент массива
primes.length //Длинна массива
primes[primes.length - 1] //Последный элемент массива
primes[4] = 9 //Добавление элемента в массив.
```
**Массивы и объекты могут содержать другие массивы и объекты**
```
let points = [
  {x: 0, y: 0},
  {x: 1, y: 1}
];

let data = {
  trial1: [[1,2], [3,4]],
  trial2: [[2,3], [4,5]]
};
```
**Создание функций и методов**
```
function plus1(x) {  //Создание функции plus1;
  return x + 1;
}

plus1(y);  //Вызов функции plus1 с аргументом y;

let square = function(x) {  //Функции являются значениеями и могут присваиваться переменным;
  return x * x;
};

square(plus(y)) //Вызов двух функций в одном выражении;
```

**Сокращенный синтаксис для определения функции "=>"**  
```
const plus1 = x => x + 1; //Вход х отображается на выход х + 1.
const square = x => х * х;
```

Метод - функция применяемая с объектами или массивами.  
```
let a = []; //Создали пустой массив.
a.push(1,2,3); //Метод push добавляет элементы в массив.
a.reverse(); //Смена порядка следования элементов.
```

***Ключевое слово "this"**  
Ключевое слово "this" ссылается на объект, в котором определяется метод или переменная.
