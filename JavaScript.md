## ОБЪЕКТЫ И МАССИВЫ  
Самым важным типом данных является "Object". Object это коллекция пар имя/значение или отображений строки на значение.  
```
let book = {
  topic: "JavaScript",
  edition: 7
};
```
**Доступ к свойствам объекта осуществляется с помощью "." или "[]".**
```
book.topic //"JavaScript"
book["edition"] // 7
```
Выражения доступа к свойствам и вызова имеют более высокий приоритет нежели любая операция.
```
my.functions[x](y);
```
my - объект.  
functions - свойство объекта, значением которого является массив функций.  
\[x\] - номер функции (индекс массива).  
(y) - аргумент функции.  

**Ошибки доступа к войствам**  
Запрашивание свойства, которое не существует не является ошибкой. Если свойство "Х" не найдено как собствунное или унаследованное свойство объекта прототипа, то вычисление выражения доступа к такому свойству дает значение undefined.

Попытка запрашивания свойства объекта, который не существует, является ошибкой. Значения null и undefined не имею свойств, и запрашивание свойств таких значений будет ошибкой.

**Наследование**  
Объекты в JS имеют набор "собственных свойств" и вдобавок наследуют набор свойств от своих объектов-прототипов. Object.create() применяется для создания объектов с указанным прототипом.  

Предположим, что запращиваем свойство "Х" в объекте "О". Если в "О" отсутствует свойство с таким именем, тогда свойство "Х" запрашивается в обхекте прототипе и так далее.

Аттрибут "prototype" объекта создает цепочку или связный список, от которого наследует свойства.

```
let unitcircle =  { r: 1}; //Объект от которого будет наследование.
let c = Object.create(unitcircle); //с наследует свойство r.
c.x = 1; c.y = 1; //с определет два собственных свойства.
c.r = 2; //c переопределяет свое унаследованное свойство.
unitcircle.r; //1, прототип не затронут.
```

**Новые совйства создаются посредством присваивания**
```
book.author = "Flanagan";
book.content = {} //Пустой объект не имеющий свойств.
```
**Условный доступ к свойствам с помощью "?."**
```
book.contents?.ch01?.sect1 //Не определенно, book.contents не имеет свойства ch01.
```  
**Глобальный объект**  
Это обыкновенный объект JavaScript, свойствами которого являются глобально определенные идентификаторы, доступные программе JavaScript. Когда интерпретатор JavaScript запускается (тлт всякий раз, когда веб браузер создает новую страницу), он создает новый глобальный объект и предоставляет ему начальный набор свойств:  
1. Глобальные константы, вроде undefined, Infinity, NaN.
2. Глобальные функции, наподобие: isNaN(), parseInt(), eval();
3. Функции конструкторов вроде Date(), RegExp(), String, Object() и Array().
4. Глобальные объекты наподобие Math и JSON.

В Node глобальный объект имеет совйство с именем "global" значением которого будет сам глобальный объект.  
В веб браузерах глобальным объектом для всего кода JavaScript, содержащегося в окне браузера, служит объект "Window", который представляет это окно. Глобавльный объект "Window" располагает ссылающимся на самого себя  свойством "window", которое можно применять для ссылки на глобальный объект.  
"globalThis" (ES2020) - стандартный способ ссылки на глобальный объект в любом контексте.  

**Проверка свойств**  
Объекты JS можна рассматривать как наборы свойств и зачастую полезно иметь возможность проверять членство свойства в таком наборе - с целью выяснения, имеет ли объект свойство с заданным именем. Это делается с помощью операции "in", посредством методов hasOwnProperty() и propertyIsEnumerable() или просто путем запрашивания свойства.  

Операция "in" с левой стороны имя войства и с правой стороны объект. Она возвращает true, если объект имеет собственное или унаследованное свойство с указанным именем:  
```
let 0 = {x: 1};
"x" in o //true, o имеет собственное свойство "х"
"у" in o //false, o не имеет свойства "у"
"toString" in o //true, o наследует свойство "toString"
```
Вместо операции "in" часто достаточно просто запросить свойство и применить "!==" для его проверки на предмет udefined. Операция "in" проводит различие между сойствами, которые не существуют, и свойствами, которые существуют, но были установленны в undefined.  

Метод hasOwnProperty() объекта проверяет, имеет ли данный объект собственное свойство с заданным именем. Для унаследованных свойств он возвращает false:  
```
let o = {x: 1};
o.hasOwnProperty("x"); //true, o имеет собственное "х".
o.hasOwnProperty("y"); //false, о не имеет свойства "у".
o.hasOwnProperty("toString"); //false, "toString" - унаследованное свойство.
```

Метод propertyIsEnumerable() возвращает true, только если именованное свойство является собственным и аттрибут enumerable имеет значение true. Определенные встроенные свойства не поддерживают перечисления. Свойства, созданные нормальным кодом JS, перечислимы при условии, что не была применена одна из методик, которая делает их неперичислимыми.  
```
let o = {x: 1};
o.propertyIsEnumerable("x"); //true, о имеет собственное перечислимое свойство "х".
o.propertyIsEnumerable("toString"); //false, не собственное свойство.
Object.prototype.propertyIsEnumerable("toString"); //false, не перечислимое свойство.
```
**Получение списка всех свойств объекта**  
Функции, которые можно применять для получения массива иен свойств:  
1. Object.keys() - возвращает массив имен перечислимых собственных свойств объекта. Она не включает неперечислимые свойства, унаследованные свойства или свойства с именами, представленными посредством значения Symbol.
2. Object.getOwnPropertyNames() - работает подобно Object.keys(), но возвращает массив имен не перечислимых собственных свойств при условии, что их имена представлены строками.
3. Object.getOwnPropertySymbols() - возвращает собственные свойста, имена которых являются значениями Symbol, перечислимые они или нет.
4. Reflect.ownKeys() - возвращает имена всех собственных свойств, перечислимых и не перечислимых, представленных как строками, так и значениями Symbol.

Эти методы можно комбинировать с for/of, for/in.  

**Object.assign(), пример копирования свойств объекта в другой объект**  
Копирование свойств одного объекта в другой:  
```
let target = {x: 1}, source = {y: 2, z: 3};
for(let key of Object.keys(source)) {
  target[key] = source[key];
}
```

Функция Object.assign() - ожидает получания в своих аргументах двух и более объектов. Она модифицирует и возвращает первый аргумент, в котором указан целевой объект, но не изменяет второй и любой последующий аргумент, где указанны исходные объекты. Для каждлго исходного объекта функция Object.assign() копирует его перечислимые собственные свойства (включая те имена свойств которые являются Symbol) в целевой объект. Свойства с одинаковыми именами переопределяются в целевом объекте, а свойства второго исходного объекта переодпределяют значение свойств с одинаковыми именами первого исходного объекта.  

Копирование свойств существующего объекта в новый объект с помощью "операции распространения" ...:  
```
let position = { x: 0, y: 0};
let dimension = {width: 100, height: 75};
letrect = {...position, ...dimension};
rect.x + rect.y + rect.width + rect.height; //175
```
В приведенном выше коде, свойства объектов position и dimension "распространяются" в объектный литерал rect, как если бы они были записаны буквально внутри фигурных скобок. Если и распространяемый об\ект, и объект, куда он распространяется, имеют свойство с тем же самым именем, тогда значением такого свойства будет то, которое поступит последним. Операция распространения распространяет только собственные свойства, но не унаследованные.

**Сокращенная запись методов**  
Когда функция определяется как свойство мы называем ее методом. В ES6 синтаксис объектных литералов был расширен, чтобы сделать возможным сокращение, где ключевое слово function и двоеточие опускаются, давая в результате такой код:  
```
let square = {
  area: function() {rerurn this.side * this.side} //Старый формат записи метода.
  area() { return this.side * this.side}, //Новый формат записи метода.
  side: 10
};
square.side();
```

Символьные имена методов:  
```
const METHOD_NAME = "m";
const symbol = Symbol();
let weirdMethods = {
  "method With Spaces" (x) { return x + 1; },

  [symbol] (x) { return x + 3; }
};
weirdMethods["method With Spaces"] (1); //2
weirdMethods[METHOD_NAME] (1); //3
weirdMethods[symbol] (1); //4
```
Чтобы сделать объект итерируемым (что позволит его применять с циклом for/of), необходимо определить метод с символьным именем Symbol.iterator.

1. toString() - не имеет аргументов, он возвращает строку, каким-то образом представляющую значение объекта, на котором он вызван.

Определение собственного метода toString:

4. toJSON() - Object.prototype на самом деле не определяет данный метод, но метов JSON.stringify() ищет мотод toJSON() в каждлм объекте, который нужно сериализовать. Если этот метод существет а объекте, подлежащий сериализвации, тогда он вызывается и сериализует его возвращаемое значение, а не первоначальный объект.

Ключевое слово "this" ссылается на объект, в котором определяется метод или переменная.  

**Методы получения и установки свойств (getter/setter)**  
Если свойство имеет метод получения и метод установки, то оно является свойством для чтения/записи. При наличии одного метода, совйсто будет доступно только для чтения или записи.  
```
let o = {
  dataProp: value,
  get accessorProp() { return this.dataProp; }, //getter
  set accessorProp(value) { this.dataProp = value; } //setter
```
Свойства с методами доступа наследуются в точности как свойства с данными.

**Методы итераторов для массивов**  
Такие мотоды проходят по массивам, передавая элементы по очереди, предоставленной нами функции, и предлагают удобный способ для итерации, отображения, проверки и сокращения массива. Все описанные далее функции принимают функцию в первом аргументе и вызывают ее по одному разу для каждого элемента массива.
1. forEach() - проходит по массиву, вызывая для каждого элемента указанную нами функцию. Оператор forEach() не предполагает какого-либо спосоза закончить итерацию до того, как все элементы будут переданы в функцию.
```
let data = [1,2,3,4,5], sum = 0;
//Вычислить сумму элементов массива
data.forEach(value => {sum+=value;}); //sum == 15
//Инкрементировать каждый элемент массива
data.forEach(function(v,i,a) {a[i] = v + 1;}); //data == [2,3,4,5,6]
```  
2. map() - передает каждый элемент массива, на котором он вызван, указанной нами функции и возвращает массив со значениями, возвращенные нашей функцией.
```
let a = [1,2,3];
a.map(x => x * x); //[1,4,9]
```
3. filter() - возвращает массив, содержащий подмножество элементов массива, на котором он был вызван. Передаваемая функция обязанна быть предикантом: функцией, которая возвращает true или false. Если возвращаемое значение равно "true" или преобразуется в "true", тогда элемент, переданный предикату, входит  подмножество и добавляется в массив, который станет возвращаемым значением.
```
let a = [5,4,3,2,1];
a.filter(x => x < 3); //[2,1]
a.filter((x,i) => i%2 === 0); [5,3,1]

a.filter(x => x !== undefined && x !== null);
```
filter() всегда возвращает плотный массив.

## СЕРИАЛИЗАЦИЯ ОБЪЕКТОВ  
Сериализация объектов представляет собой процесс преобразования свостояния объекта в строку, из которой он может быть восстановлен. Функции JSON.stringify() и JSON.parse() сериализуют и восстанавливают объекты JS.  
```
let o = {x: 1, y: {z: [false, null, ""]}};
let s = JSON.stringify(o); //Сериализуем объект "о".
let p = JSON.parse(s); //Десериализуем сериализованный объект "s".
```  


## ЛЕКСИЧЕСКАЯ СТРУКТУРА

**Текст**  
В качестве типа JS для представления текста применяется строка. Строка - это неизменяемая упорядоченная последовательность 16-битных значений, каждое из которых представляет символ Unicode. Длинна строки - количество содержащихся в ней 16-битных значений. Строки используют индексацию, начинающуюся с 0. Пустая строка - это строка с длинной 0. Символы Unicode, кодовые точки которых не умещаются в 16 бит, кодируются с использованием привил UTF-16 в виде последовательностейиз двух 16-битных значений. Строки являются итерируемыми, применение for/of или ... приведет к проходу по дуйствительным символам строки, а не по 16-битным значения. Для включения строки в код JS используются символы ``` ' " ` ```.  

```
"" //Пустая строка, содержит ноль символов.
'testing'
"3.14"
'name="myform"'
`"She said 'hi'", he said.`
```
Строки в обратных кавычках допускают наличие в строковых литералах встроенных (интерполированных) выражений JavaScript.  

**Операция delete**  
delete - удалить свойство объекта или элемента массива. Удаление элемента массива оставляет в массиве "дыру" и не изменяет длину массива. Резулютирующий массив становится разреженным. Неконфигурируемые свойства защищенны от удаления. В строгом режиме оператор генерирует ошибку SyntaxError если ее операнд является неуточненным идентификатором, таким как переменная, функция или параметр функции, она работает, только когда операнд представляет собой выражение доступа к свойству. Операция delete удаляет только собствунные свойства, но не унаследованные. delete вычисляется как true, когда применяется с выражением, не являющимся выражением доступа к свойству. Операция delete не удаляет свойства, которые имеют аттрибут configurable, установленный в false.

При удалении конфигурируемых свойств глобального объекта в нестрогом режиме можно опускать ссылку на глобальный объект и указывать после операции delete имя свойства.  
```
globalThis.x = 1; //Создать конфигурируемое свойство глобального объекта (никаких let или var).
delete x; //true, свойство можно удалить.

delete x; //SyntaxError в строгом режиме.
delete globalThis.x; //Это работает.
```

**null и undefined**  
null - применяется для указания на отсутсьвие значения. Можно считать объектным значением.  
undefined - применяется для указания на отсутсьвие значения. Значение переменных, которые не были инициализированны, не существующие переменные. Значение undefined также является возвращаемым значением функций, явно не возвращающих значение, и значение параметров функций для которых аргументы не передались. undefined представляет собой заранее определенную глобальную константу.  

null и undefined служат признаком отсутствия значения. Операция "==" считает их равными. Для их различия применяется операция "===".

**Преобразование объектов в элементарные значения**  
1. prefer-string
2. prefer-number
3. no-preference: все встроенные типы JavaScript, исключая Date, реализуют данный алгоритм как prefer-number. Класс Date реализует его как prefer-string.

Преобразование объектов в булевские значения - все объекты преобразуются в true.  

Преобразования в операциях особого случая:  
1. Операция "+" выполняет сложение чисел и конкатенацию строк. Если любой из операндов оказыавется объектом, то интерпретатор преобразует его в элементарное значение с применением алгоритма no-preference. После получения двух элементарных значений проверя.тся их типы. Если один из аргументов является строкой, тогда другой преобразуется в строку и выполняется операция конкатенации строк. Иначе оба аргумента преобразуются в числа и складываются.
2. Операции "==" и "!=" проверяют на предмет равентсва и неравенства свободным способом, который допускает преобразование типов. Если один операнд представляет собой объект, а другой элементарное значение, тогда эти операции преобразуют объект в элементарное значение, используя алгоритм no-preference, и затем сравнивают эти два значения.
3. Операции "<", "<=", ">", ">=" сравнивают порядок своих операндов и могут  применяться для сравнения как чисел так и строк. Если один из операндов объект, то он преобрахуется в элементарное значение с использованием алогритма prefer-number.

**Условная операция (?:)**  
Условная операция - единственная операция с тремя операторами, которая иногда назвается "тернарной операцией". Первый операнд находится перед ?, второй между ? и :, третий после :.
```
x > 0 ? x : -x
```
Первая операнд вычисляется и интерпретируется как булевское значение. Если значение первого операнда истинное, тогда вычисляется второй операнд и возвращается его значение. В противном случае, когда значение первого операнда ложное, то вычисляется третий операнд и возвращается его значение.
```
greeting = "hello " + (username ? username : "there");
```

**Операция выбора первого определенного операнда**  
Операция выбора первого определенного операнда ?? вычисляется как ее первый определенный операнд: если левый операнд не является null или undefined, тогда она возвращает его значение. Иначе операция ?? возвращает значение правого операнда.  
```
let options = {timeout: 0, title: "", verbose: false, n: null};
options.timeout ?? 1000 //0, как определенно в объекте.
options.title ?? "Untitled" //"", как определенно в объекте.
options.verbose ?? true //false, как определенно в объекте.
options.quiet ?? false //false, свойство не определенно.
options.n ?? 10 //10, свойство равно null.
```

## ОПЕРАТОРЫ  
**Условный оператор "if"**  
Оператор if - управляющий оператор, который выполняет операции условным образом. Он имеет две формы. Вот первая:  
```
if (выражение)
  оператор
```
Сначала вычисляется выражение. Если результирующее значение истинно, тогда оператор выполняется. Если выражение ложно, то оператор не выполняется.
Во второй форме оператора "if" вводится конструкция else, которая выполняется, когда выражение равно false. Вторая форма оператора "if":  
```
if (выражение)
  оператор
else
  оператор2
```
Хорашая практика заключать тело операторов в фигурные скобки {}.  

Оператор "else if" вычисляет выражение и в зависимости от результата выполняет одну из двух порций кода.  
```
if (n === 1) {
  //Выполнить блок кода #1
} else if (n === 2) {
  //Выполнить блок кода #2
} else if (n === 3) {
  //Выполнить блок кода #3
} else {
  //Выполнить блок кода #4
}
```

**Условный оператор "switch"**  
```
switch(выражение) {
  операторы
}
```
Когда оператор switch выполняется, он вычисляет значение выражения и затем ищет метку case, результат вычисления выражения который дает то же самое значение (одинаковость определяется операцией ===).  
```
switch(n) {
case 1: //Начать здесь, если n === 1
  //Выполнить блок кода #1
  break; //Остановиться здесь.
case 2: //Начать здесь, если n === 2
  //Выполнить блок кода #2
  break; //Остановиться здесь.
default: //Если все остальное не выполнилось
  //Выполнить блок кода #2
  break;
}
```

**Цикл while**  
Для выполнения оператора while интерпретатор сначала вычисляет выражение. Если значение выражения ложное, тогда интерпретатор пропускает оператор, служащий телом цикла, и переходит к следующему оператору в программе.  
```
let count = 0;
while(count < 10) {
  console.log(count);
  count++;
}
```
**Цикл do/while**  
Цикл do/while похож на цикл while, но только выражение цикла проверяется в конце цикла, а не в начале. Таким образом, тело цикла всегда выполниться хотя бы раз.  
```
...
do {
  console.log(a[i]);
} while(++i < len);
```
**Цикл for**  
```
for(инициализация; проверка; инкрементирование)
  оператор

for(let count = 0; count < 10; count++) {
  console.log(count);
}

let i, j, sum = 0;
for(i = 0, j = 10; i < 10; i++, j--) {
  sum += i * j;
}
  
```

**Операторы return и yield**  
Оператор return внутри функции указывает значение вызовов этой функции. Оператор return может встречаться тоько внутри тела функции. Его появление в любом другом месте будет синтаксической ошибкой. Выполнение оператора return приводит к тому, что содержащая его функция возвращает значение выражения вызывающему коду.
```
return выражение;
```
Без оператор return вызов функции просто обеспечивает выполнение всех операторов в теле функции по очереди, пока не будет достигнут конец функции, после чего управление возвращается вызывающему коду. В таком случае выражение вызова вычисляется как undefined. Оператор return также может применяться без выражения чтобы функция возвращала undefined вызывающему коду.  

Оператор yield во многом схож с оператором return, но используется только в генераторных функциях для выпуска следующего значения в генерируемой последовательности значений без фактического возврата управления.  
```
function* range(from,to) {
  for(let i = from; i <= to; i++){
    yield i;
  }
}
```

## ИСКЛЮЧЕНИЯ  
**Операторы throw, try/catch,finally**  
throw - оператор исключения, который указывает, что возникло какое-то необычное условие или ошибка.  
```
throw выражение;
```
Результатом выражения может быть значение любого типа. В throw можно указывать число, представляющее код ошибки, или строку, которая содержит понятное человеку сообщение об ошибке. 
когда интерпретатор самостоятельно генерирует ошибку, используется класс Error и его подклассы. Объект Error имеет свойство name, указывающее тип ошибки, и свойство message, которое хранит строку, переданну функции конструктора.  
```
if (x < 0) throw new Error("Значение х не должно быть отрицательным!");
```
Когда сгенерированно исключение, интерпретатор немедленно останавливает нормальное выполнение программы и переходит к ближайшему обработчику исключений. Обработчики исключений записываются с использованием конструкции catch.  

В конструкции try определяется блок кода, чьи исключения должны быть обработанны. За блоком try следует конструкция catch, которая представляет собой блок операторов, вызываемый при возникновении исключения внутри блока try. Псоле конструкции catch находится блок finally, содержащий код очистки, который гарантированно выполнится вне зависимости от того, что произошло в блоку try. Блоки catch и finally не обязательны, но try должен сопровождаться, по крйней мере, одним из этих блоков.  
```
try {
  //КОД
}
catch(e) {
  //КОД ИСКЛЮЧЕНИЯ
}
finally {
  //КОД ОЧИСТКИ
}
```
